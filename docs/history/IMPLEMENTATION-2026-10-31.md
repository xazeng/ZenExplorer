# 实现与验证记录

## 实现选择

- 原生 C++20、Win32、CMake、MSVC，构建目标 x64，静态 MSVC 运行库。使用系统 SDK/COM，无新增第三方代码依赖。
- 主程序初始化 STA/OLE，在单 UI 线程承载各标签的 IExplorerBrowser；系统内部线程不受此约束。
- TabStrip 负责标签和分组 UI，Model 保存独立于 HWND 的状态；ShellView 承载系统视图及适配。后台首次未激活的标签不实例化视图，已加载视图暂保留至关闭。
- 每次独立文件任务启动一个 ZenExplorer.exe 的任务模式进程，通过 IFileOperation 执行复制、移动、删除。系统目标的 IDropTarget 仅用于拖放效果协商，不在主窗口调用实际 Drop。系统操作窗口归属工作进程，不使用 Job Object，也不猜测系统命令的异步存活时间。
- 单次任务包含入口类型、目标、源文件路径、永久删除标志、按键状态、来源允许效果、偏好效果和屏幕位置。文件执行不延迟读取全局剪贴板，不依赖主进程数据对象。普通文件拖放可附带封送后的异步来源完成通知接口，工作进程结束时回报；不用于读取虚拟内容。
- 任务文件先完整落盘，创建工作进程成功后返回。此时任务描述不依赖主进程内存；这表示持久交付及进程创建成功，不表示文件操作已经成功。工作进程的系统 UI 报错并写结果文件。启动进程失败由主窗口提示。
- 并发策略目前为一任务一进程，不提供统一队列；这是原型实现选择，并非新增业务约定。

## 会话格式和兼容性

使用带魔数、版本、长度和校验值的二进制文件，会话当前版本 2。本轮操作任务使用新魔数 0x324E455A、版本 1，不兼容旧操作任务；增加有界的异步来源通知数据。会话保存时写临时文件、FlushFileBuffers、完整替换并保留备份。配置文件长度、集合长度、布尔值和状态结构都进行检查。

按确认要求：后续新版需要读取既有版本；旧版遇到未来版本时不覆盖原配置。不导入 Tablacus Explorer 的配置。本轮为初版，不存在旧 ZenExplorer 数据迁移。后续新增字段必须调整版本和迁移逻辑，保留对版本 1、2 会话的读取。

自动保存约 700 ms 合并变更，正常退出再次保存。强制结束可能丢失尚未落盘的最后变更。文件任务与会话独立保存，遗留任务不自动重放。

## 文件操作入口覆盖

| 入口 | 当前实现 | 验证状态 |
| --- | --- | --- |
| 复制/剪切快捷键和标准菜单 | 当前视图系统 copy/cut 命令，再固化剪贴板 | Shell 回归通过，实际 Ctrl+C/Ctrl+V 通过 |
| Ctrl+Z 与标准撤销菜单 | 当前 Shell 背景菜单中的系统撤销命令 | shell_commands 回归通过 |
| 粘贴快捷键和标准菜单 | 普通文件快照交给独立 IFileOperation；不支持的来源拒绝 | 实际键盘及冲突窗口测试通过 |
| Delete/Shift+Delete 和标准删除菜单 | 独立 IFileOperation；不支持的项目拒绝 | 普通删除回归通过；永久删除系统提示待实机验收 |
| 普通文件视图左键拖放 | 在实际 SysListView32/DirectUIHWND 注册入口，系统协商效果后独立交付 | 跨栏子文件夹、空白区域、外部资源管理器拖入通过 |
| 其他视图及特殊目标拖放 | 不声明统一接管或独立执行保证 | 待按具体入口确认；虚拟文件不属于本轮范围 |
| 向外部资源管理器拖放 | 外部目标执行 | 由外部软件决定生命周期 |
| 第三方菜单命令 | 原 Shell 扩展执行 | 不保证独立运行 |

拖放经过标签栏使用悬停展开/切换；独立任务交付后脱离标签栏计时判断，明确取消时恢复悬停展开（用户后续交互优先）；完成时保留展开。外部目标的成功判定依赖其反馈 performed-drop-effect/logical-performed-drop-effect 格式，未反馈时按未成功处理。该兼容性还需实测。

### Shell 新建命令、剪贴板和撤销

### 2026-10-31 普通文件独立操作与实机验证

本节替代前述系统命令改造中的文件传输执行方案及回退策略。虚拟文件暂不支持；右键拖放及创建快捷方式不支持。普通文件复制、移动、删除统一在独立进程调用 IFileOperation；不支持的传输来源直接拒绝，不回退到主窗口。系统负责冲突、进度、副本命名与回收站处理；同目录复制单独启用系统重名生成副本选项。

拖放保留系统目标的效果协商，在实际文件视图注册接收入口。DirectUI 项目命中使用当前视图窗口的辅助功能对象及唯一显示名映射，避免拖动影像干扰命中，也避免子文件夹命中失败后误投外层目录。显示名存在歧义时拒绝操作。取消或交付失败恢复标签组临时展开状态。

普通文件来源支持异步拖放时，在交付前启动异步操作并封送完成通知接口，由工作进程通知实际完成效果。移动由目标执行，避免来源再次删除；仅允许 MOVE 且无异步通知能力的来源安全拒绝。封送接口只用于完成通知，文件执行仍使用快照路径，不构成虚拟文件支持。冲突时的等待回调与最终完成分开记录，防止用户成功覆盖后仍误报取消。
